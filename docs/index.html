Contract

Precise where it matters.

Encoding, identity, integrity, and authentication are separate concerns. Swift-CBORLD exposes each boundary instead of letting one checksum or serialization mode imply more than it proves.

01 / WIRE

Compatibility first

Established JavaScript-compatible bytes remain the default representation.

02 / ORDER

Determinism by choice

Length-first and core deterministic RFC 8949 profiles are explicit opt-ins.

03 / LIMITS

Bounded input

Input size, nesting, container count, diagnostic retention, and indefinite items are controlled.

04 / PINS

Frozen semantics

Context and application dictionary fingerprints are checked before semantic use.

05 / HASH

Named hash domains

Transport, structure, contexts, and dictionaries never share an ambiguous digest meaning.

06 / VIEW

Inspectable failure

Envelope metadata, byte offsets, container paths, and aggregate verification reports make rejection explainable.

Architecture

CPU-correct at the core.

Whole-document CBOR-LD transformation stays in the native processor. Dense, independent byte and integer work can cross a versioned provider boundary only when its result survives package-side acceptance checks.

ApplicationSwift model or JSONValue

Async context policy and caller-selected limits.

CBORLD coreSemantic transform

Context inheritance, codecs, dictionaries, envelopes.

ValidationCPU reference

Exact bytes, integer semantics, diagnostics, digests.

Optional backendCompute provider

Bounded families accepted one result at a time.

Security boundary

Integrity is not identity.

A transport digest detects changed bytes. A structural fingerprint detects changed JSON-shaped structure. Neither proves who produced a document, and neither establishes RDF dataset equivalence.

For untrusted input

Set conservative byte, nesting, and container limits. Reject duplicate keys and indefinite-length items where a unique representation is required. Pin remote contexts and document dictionaries.

For signed claims

Canonicalize with a standards-appropriate JSON-LD/RDF algorithm and place signatures or MACs in an enclosing protocol with an explicit signing profile. Swift-CBORLD adds no authentication field to the wire envelope.
